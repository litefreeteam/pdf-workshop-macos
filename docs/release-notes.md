PDF 工坊 v2.1.0：新增按页码拆分。

- 工具栏和文件菜单新增「按页码拆分」，快捷键为 ⌘⌥D。
- 输入 `1-3, 4-6, 7`，每组单独生成一份 PDF；支持中文逗号、分号和换行分组。
- 新增「每页单独导出一份」，可把全部页面逐页拆分。
- 实时显示份数、选中页数和遗漏页数，拦截越界、倒序和重复/重叠范围。
- 按输入分组顺序导出，包含当前未另存的图片替换、旋转和页序调整。
- 继续支持按大小拆分、PDF 转图片与图片回填；13 组检查全部通过。

支持 macOS 13+，包含 arm64 与 x86_64。Apple Silicon 已本机测试，Intel 为交叉编译。应用为本地临时签名，未做 Apple 公证；详细说明见 README。

按页码拆分只导出指定页面；未填写的页码不导出。按大小模式中，单页超过上限时会停止并提示。数字签名、复杂表单、书签和附件不保证保留。解锁后的导出副本不设密码。
