将「PDF 图片工坊」和「PDF 轻拆」整合为一个原生 macOS 客户端。

- 导出 PDF 页面为 PNG，支持 150 / 300 / 600 DPI。
- 将修改后的图片回填 PDF，支持批量页码匹配。
- 旋转页面、调整页序，另存 PDF。
- 按每份实际大小上限拆分 PDF，支持自定义 MB、进度、取消与结果校验。
- 编辑后的当前文档可直接拆分，无需先保存。
- 全程在本机处理，无第三方运行依赖。

支持 macOS 13+，包含 arm64 与 x86_64。Apple Silicon 已本机测试，Intel 为交叉编译。应用为本地临时签名，未做 Apple 公证；详细说明见 README。

单页超过大小上限时会停止并提示，不会自行压缩页面。数字签名、复杂表单、书签和附件不保证保留。解锁后的导出副本不设密码。
